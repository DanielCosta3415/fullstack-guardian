# security-review

1. Faça modelo de ameaças e enumere limites de confiança.
2. Verifique autorização no servidor, sessões, injeções, segredos, dependências e exposição de serviços.
3. Prefira testes locais não destrutivos e ambiente autorizado.
4. Documente achados com impacto e evidência; solicite aprovação para testes intrusivos.
5. Escalone S13/S14/S15 e revisor G01 em riscos altos.
