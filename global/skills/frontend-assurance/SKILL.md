# frontend-assurance

1. Rastreie a jornada e os componentes afetados.
2. Verifique estados vazios, carregando, erro, retry, foco, teclado, rotulagem e dispositivos suportados.
3. Rode testes e medições disponíveis; não afirme conformidade WCAG nem Core Web Vitals sem testes pertinentes.
4. Consulte S05/S06/S07/S17 conforme risco e superfície.
